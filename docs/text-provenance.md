# 教學文字來源清冊

盤點日期：2026-08-08。

## 結論

學生前台的概念解說、造字故事、字例白話說明、自測題目、大師對戰台詞與家長陪學文案，均在本專案開發過程中重新撰寫，不是從教育部字典、其他教學網站或文章整段貼入。

漢字分類、歷史人物姓名、六書名稱與字形演變等「事實或概念」不等於本站原創；本站主張的是具體教學文字、故事安排、題目設計與介面編排。編輯端仍保存古籍與正式資料的核對欄位，但學生前台不展示其逐字原文或外部資料連結。

## 本輪教學事實核對

- 教育部《重編國語辭典修訂本》「假借」釋義採「本無其字，依聲託事」：<https://dict.revised.moe.edu.tw/dictView.jsp?ID=89728&la=0&powerMode=0>
- 教育部《重編國語辭典修訂本》「形聲」條目：<https://dict.revised.moe.edu.tw/dictView.jsp?ID=110679&la=0&powerMode=0>
- 國家教育研究院電子報說明《說文解字》九千三百五十三個小篆中，形聲字約占九成：<https://epaper.naer.edu.tw/edm?content_no=1884&edm_no=72>

故事中的「有邊讀邊，沒邊讀中間」明列為玩笑而非規則；轉注採互訓說作教學整理，並明示歷來異說與時間、地域並非必要條件。

## 本輪前台收斂

1. 字卡不再顯示《說文解字》逐字節錄、核對狀態或教育部連結。
2. 概念頁與故事頁移除古籍原句，改用本站白話表達。
3. 自測題不再要求辨認古籍原句。
4. 公開權利頁不提供外部可點資料連結，只說明利用界線。

## 抽樣檢索

以四段具有辨識度的本站句子做公開網路逐字搜尋，包括「刀」字解說、成熟漢字的形音義說明、故事記憶護欄與形聲判讀句。未找到相同外部段落。這是抽樣風險檢查，不是對全網所有內容的司法級比對或絕對原創保證。
