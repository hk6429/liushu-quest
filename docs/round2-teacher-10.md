# 六書造字堂第二輪國中國文教師審查（T01–T10）

審查基準：`c0b136f`。本清單只收錄上一輪 `docs/gamification-audit-40.md` 未涵蓋的問題；上一輪已處理的傳說／史實分層、四體二用、聲符不是保證等原則，不重複列案。本輪聚焦學生能否理解、說理、辨析與在一節課內完成學習閉環。

| ID | 基準版證據與教學影響 | 修正策略 | 可驗收條件 |
|---|---|---|---|
| T01 | `js/concept.js` 開頭直接進入「文字誕生之前」，未先告訴學生學完要會做什麼。學生容易把長頁面當知識展覽，不知道作答時要提出哪種證據。 | 增加三項學習目標與「我判斷是＿＿，因為＿＿」成功標準，把成果改成可觀察的完整說理。 | 概念頁首屏可見學習任務與完整句型；測試能找到二者。 |
| T02 | 基準故事寫「文字的三要素，就是這麼來的」，概念頁也以固定的形、音、義勾叉呈現，容易讓學生誤以為一字必然只對應一音一義。 | 改稱「觀察漢字的三個面向」，補上多音字、一字多義需回到詞語與語境的限制。 | 概念與故事皆明說「三個面向」，並出現多音／多義提醒。 |
| T03 | 基準六書總覽排列「象、指、會、形、轉、假」，正文與故事卻依「象、指、會、假、形、轉」編章；同頁順序衝突，增加工作記憶負擔。 | 兩頁統一採現代常見教學次序「象、指、會、形、轉、假」，明示這是本站教學編排，不是《說文解字．敘》原序或歷史時間表；另列原典序數「指、象、形、會、轉、假」避免錯誤歸因。 | 兩頁章次均為象形→指事→會意→形聲→轉注→假借；皆出現「本站教學編排」、非原序與非時間表護欄。 |
| T04 | 六章皆用「細部分類（小學生版）」，與國中受眾及會考所需的「依證據判斷」不相稱，也沒有固定解題程序。 | 全部改成「國中判讀」，每章提供可執行的觀察或判斷步驟。 | 不再出現「小學生版」；概念頁恰有六個「國中判讀」段落。 |
| T05 | 象形只說「照著畫」，指事只說「加記號」，但未直接比較最常混淆的「本」與「休」。學生可能見到「木」就只憑外觀歸類。 | 用「本為木加指示記號／休為人木兩個有義部件」做並列辨析，另追問「本為何不歸象形」。 | 頁面能找到兩個對比問題，答案明確落在「前者指事，後者會意」。 |
| T06 | 基準會意章說「同一個零件一直疊，意思會變大」，又以「人靠樹、日月同框」直接下結論，容易把任意拆字或圖像聯想當文字學證據。 | 將重複規則限縮為「部分字例」，明說入門拆解只是線索，個別字仍須核對古文字形與可靠釋形。 | 概念與故事均有反過度類推文字；概念頁明示不能把所有看圖聯想當證據。 |
| T07 | 基準形聲標題為「半邊表義＋半邊表音」，故事也寫「一半用氵……另一半……」，會誤導學生把形符、聲符理解成面積各半。 | 統一改為「一部分表義、一部分提示讀音」，明說兩部分不一定各占一半。 | 兩個檔案不再用「半邊／一半用」作定義，且兩頁都有比例護欄。 |
| T08 | 基準形聲章把六種位置寫成「找形符，就像玩捉迷藏」，卻沒有驗證流程；學生容易把偏旁位置當答案，或看到現代同音就判形聲。 | 提供「義→音→證據」三步查，強調位置只協助觀察，並用「江／工」說明古今音變。 | 概念頁出現三步查與「位置不是分類答案」；故事頁也以部件功能優先。 |
| T09 | 雖然資料 schema 已有雙軸，但基準學生頁只在總覽抽象說四體二用，沒有示範同一個字如何依題幹得到不同答案。 | 新增「一字兩問」，用「莫＝會意構形＋假借關係」「考＝形聲構形＋轉注關係」示範，故事同步提醒。 | 頁面可逐字驗出莫、考兩組雙軸答案；故事明說考字構形為形聲。 |
| T10 | 基準故事連續閱讀六章，只有每章「你學到的字」，沒有先回想再揭答的提取練習；長篇閱讀容易形成「看懂了」錯覺。 | 六章各加入原生 `details`「停看聽」，概念頁各章也有立即檢核，尾聲加入可口頭操作的離堂任務。 | 故事恰有六個停看聽；概念頁至少七個檢核；故事含離堂任務。 |

## 課堂使用建議

一節課可先讓學生只讀每章粗體句，再兩人一組完成「停看聽」。教師抽問時固定要求：「題目問的是構形還是用字關係？你的證據是什麼？」最後以「本、休、江、莫」任選一字做離堂口說或便利貼。若學生只能說類別、不能說理由，尚未達成本頁成功標準。
