# 六書造字堂：四位遊戲化大師 40 項修正清單

本清單由四條獨立審查線產出，每線 10 項。完成狀態以測試、實際操作與正式站回讀為準，不以程式碼存在取代驗收。

## 大師一：遊戲循環與成長（G01–G10）

| ID | 發現 | 本輪修正目標 |
|---|---|---|
| G01 | 首次進站直接落入長篇概念頁，沒有新手路徑 | 三步導引、跳過與重看 |
| G02 | 到期卡、弱點字與新字皆有資料，卻沒有唯一下一步 | 今日修行目標與情境 CTA |
| G03 | `_concept` 會被建立成字卡並誤算精通；對戰概念題又漏記 | 概念統計與真實字卡完全拆開 |
| G04 | 戰績宣稱弱點優先，但閃卡牌組沒有使用弱點排序 | 弱點／到期／新卡混合牌組 |
| G05 | 只顯示精通或未精通，盒序成長不可見 | 初識到精通五階成長梯 |
| G06 | 全庫亂數受資料量偏斜，六書覆蓋與難度不穩 | 六書均衡藍圖與自適應難度 |
| G07 | 大師只有攻擊差異、題目同質且戰鬥可能拖長 | 大師專長題組、十回合終局與賽後分析 |
| G08 | 自測與勝利只有文字，缺少有限里程碑 | 六書印譜成就與一次性授予 |
| G09 | 只有閃卡寫入練功日，且 UTC 日期會錯算台灣午夜 | 三模式活動、台灣日界線與連續學習 |
| G10 | 重玩只有重新亂數，沒有可比較挑戰 | 每日字陣、首次／最佳成績與安全分享卡 |
