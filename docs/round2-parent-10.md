# 第二輪家長視角：10 項修正

本輪只計入上一輪 `gamification-audit-40.md` 未涵蓋的家庭陪學問題；判準是家長能否在不熟悉文字學、也不製造分數壓力的情況下，帶孩子完成一次短而有效的學習。

| ID | 問題證據 | 修正 | 驗收條件 |
|---|---|---|---|
| H01 | 首頁只有學生功能分頁，家長第一次進站不知道從哪裡開始陪 | 首頁新增常駐「家長陪學」入口 | 任何分頁頂端都能打開指南 |
| H02 | 網站內容量大，沒有一回合可完成的家庭節奏 | 提供 10 分鐘三步驟 | 明列共讀、說理、收尾三步 |
| H03 | 家長容易直接問「答案是哪一類」，孩子只剩猜分類 | 提供三句要求觀察與證據的提問 | 問句包含部件、構形／用字、爭議依據 |
| H04 | 戰績容易讓陪學滑向分數評價 | 加入「先描述策略，再談答案」的低壓力回饋 | 指南明示不公開排名與錯題用途 |
| H05 | 家長或孩子可能需要較大字級，原站只能依瀏覽器自行縮放 | 加入標準／放大閱讀字級並記住選擇 | 切換後全站字級改變，重開仍保留 |
| H06 | 戰績頁指標完整，但家長需要一句話理解孩子目前狀態 | 將已接觸、穩定精通、待複習轉成白話摘要 | 摘要不只呈現正確率，且顯示 220 字總量邊界 |
| H07 | 家長不知道此刻應共讀、複習或自測 | 依已接觸、弱點與答題量提供單一下一步 | CTA 能直接進入故事、閃卡或自測 |
| H08 | 頁尾只說本機保存，未在陪學決策點解釋何時會跨裝置 | 指南說明預設本機、主動使用學習紀錄才加密同步 | 家長入口內可直接讀到資料界線 |
| H09 | 共用裝置可能有多位孩子，紀錄容易混用 | 提醒先切換孩子並串接既有家庭模式 | 按鈕可開啟家庭工具；未載入時有狀態提示 |
| H10 | 沒有明確停止訊號，家庭練習可能不斷延長 | 加入 10 分鐘陪學計時與正向休息訊息 | 啟動後顯示倒數，結束提醒休息且不懲罰中止 |

## 實作邊界

- `index.html`：家長入口與載入點。
- `js/parent.js`：摘要、下一步、家庭工具、字級與計時。
- `css/style.css`：桌機／手機陪學面板與放大字級。
- `scripts/smoke.mjs`：實際操作驗收。
