# 六書造字堂 詞條 schema（凍結版 v1 — subagent 不得更動）

每筆詞條 = 一個漢字：

```json
{
  "id": "TEMP",
  "char": "日",
  "zhuyin": "ㄖˋ",
  "category": "象形",
  "sub": null,
  "level": "基礎",
  "explain": "甲骨文畫太陽的輪廓，中間一點表示日中有物（或作區別符號）。畫成其物、隨體詰詘的典型象形字。",
  "shuowen": "實也。太陽之精不虧。",
  "disputed": false,
  "dispute_note": ""
}
```

## 欄位規則

- `id`：一律填 `"TEMP"`，merge 腳本統一重新編號（c0001…）。
- `char`：單一漢字（正體），全庫不得重複。
- `zhuyin`：該字現行國語讀音（教育部審訂音），聲調符號用 ˊˇˋ˙，一聲不加符號。多音字取最常用讀音。
- `category`：只能是 `象形` `指事` `會意` `形聲` `轉注` `假借` 六個值之一。
- `sub`：細類。只有兩種情況可填，其餘一律 `null`：
  - 會意 → `同體會意` 或 `異體會意`
  - 假借 → `有借有還` 或 `有借不還`
- `level`：`基礎`（典型字例、國中會考常見）／`進階`（需理解構字理據才判得出）／`挑戰`（易誤判、跨類爭議、學說有別）。
- `explain`：60–150 字繁體中文，說明字形演變與為何屬於該書類。形聲字必須點出「形符＋聲符」各是什麼；會意字必須點出組成部件；假借字必須點出本義與借義。
- `shuowen`：《說文解字》釋語原文節錄（可簡短），查不到確切原文就填 `""`，**不可自己編一句假裝是說文**。
- `disputed`：該字的六書歸類在學界（或教學現場）有明顯分歧時填 `true`，並在 `dispute_note` 一句話說明分歧（例：「北」多數字書歸會意（二人相背），部分教材列指事）。`disputed:true` 的字 level 一律 `挑戰`。

## 誠信鐵律

分類必須符合文字學通說（說文解字＋現行教材共識，可交叉小學堂、教育部異體字字典的字源資料）。**不確定的字寧可不收，不可硬湊配額**；湊不滿指定字數就在回報中老實說明缺口。
